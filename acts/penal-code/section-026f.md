# 26F. “Negligently”
Chapter: CHAPTER 2 GENERAL EXPLANATIONS

(1) Whoever omits to do an act which a reasonable person would do, or does any act which a reasonable person would not do, is said to do so negligently.

[15/2019]

(2) Where doing an act negligently is a fault element of an offence, that fault element is also established where that act is done intentionally, knowingly or rashly.

[15/2019]
