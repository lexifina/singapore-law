# 6A. Definitions to apply to this Code and other written law
Chapter: CHAPTER 2 GENERAL EXPLANATIONS

Every definition of a word or expression which is explained in sections 22A to 26H (except the definitions of “dishonestly” and “fraudulently” in sections 24 and 25, respectively) applies to any offence in this Code or in any other written law unless that written law expressly provides for a definition or explanation of that same word or expression.
