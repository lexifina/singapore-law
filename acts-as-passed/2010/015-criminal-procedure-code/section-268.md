# 268. Hearsay evidence admissible only under this Code or other law
Part: PART XIV EVIDENCE AND WITNESSES Division 1 — Preliminary
Division: Division 2 — Admissibility of certain types of evidence

In any criminal proceedings, a statement other than one given orally in those proceedings is admissible as evidence of any fact stated therein to the extent that it is so admissible by this Code or any other written law.
