# 25. Repeal and re-enactment of section 120B

Section 120B of the Penal Code is repealed and the following section substituted therefor:

“Punishment of criminal conspiracy 120B. Whoever is a party to a criminal conspiracy to commit an offence shall, where no express provision is made in this Code for the punishment of such a conspiracy, be punished in the same manner as if he had abetted such offence.”.
