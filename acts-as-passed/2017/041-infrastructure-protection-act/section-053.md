# 53. Security directive for maintenance of security measures for special infrastructure
Part: PART 5 SECURITY DIRECTIVES

(1) The Commissioner may issue a security directive to the responsible person of a special infrastructure if the responsible person contravenes section 40(2)(b) or 47(1)(b).

(2) The security directive may —

(a) direct the responsible person to take any action or measure specified in the security directive, to secure compliance with the relevant provision mentioned in subsection (1);

and

(b) specify the date on which the security directive is to take effect and the period within which any direction in the security directive must be complied with.
