# 17. Applying false manufacturer’s code
Part: PART III MANUFACTURER’S CODE

(1) Any person who falsely applies, or causes to be falsely applied, to an optical disc a manufacturer’s code or any mark so resembling a manufacturer’s code as to be calculated to deceive shall be guilty of an offence.

(2) In any proceedings for an offence under subsection (1), it shall be a defence for the person charged to prove that he acted without intent to deceive or defraud.
