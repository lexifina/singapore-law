# Singapore law: paused, not yet law

This repository holds no law yet. It is a placeholder for Singapore's legislation as git history (one commit per amending law, dated the day it took effect), following the same rules as the other lexifina law repositories.

It is paused because Singapore Statutes Online (sso.agc.gov.sg) blocks automated access: after a few requests its web application firewall answers with a browser challenge, which we will not get around. Its robots.txt also asks for a 6-second crawl delay, which would make a full history take days to fetch.

It will be built when there is a permitted route, such as a bulk export from the Attorney-General's Chambers.
